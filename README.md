# Gobo Finder

Find a gobo in your lighting library from a photo — on the computer or with your phone.
Найдите гобо в библиотеке по фотографии — на компьютере или с телефона.

## Download / Скачать

Open the latest release: **[Releases → Latest](../../releases/latest)**

| Platform / Система | File / Файл |
|---|---|
| Windows (x64) | `GoboFinder-<version>-windows-x64.zip` — unzip, run `GoboFinder\GoboFinder.exe` |
| macOS Apple Silicon | `GoboFinder-<version>-macos-arm64.zip` |
| macOS Intel | `GoboFinder-<version>-macos-x64.zip` |
| Android (phone) | `GoboFinder-<version>-android.apk` |

The builds are not signed: Windows SmartScreen may warn ("More info" → "Run anyway"); on macOS right-click the app → "Open".
Сборки не подписаны: в Windows — «Подробнее» → «Выполнить в любом случае»; в macOS — правый клик → «Открыть».

## Updates / Обновления

The program checks this page for a newer version (at most once a day; only a request to GitHub, no data about you is sent). It can be switched off in Settings.
Программа проверяет эту страницу на наличие новой версии (не чаще раза в сутки; только запрос к GitHub, никаких данных о вас не передаётся). Отключается в настройках.

This repository contains releases only. / В этом репозитории только выпуски программы.
